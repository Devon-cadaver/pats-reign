# Pats Reign

A Viking ocean game for phone browsers. Sail a longship across a huge monster sea, fish up timber, iron and gold,
fight sea serpents, sharks, krakens and raider ships in battle mini-games, and grow your ship from a little faering
into Pat's great drakkar. Ride out storms, rogue waves, waterspouts and sea tornadoes, and catch a lightning bolt for
Thor's Fury. Slay the Kraken, Jormungandr and the Elder One to reign over the sea.

Built with Three.js and Vite, on the same engine pieces as Dead City.

## Play locally

```bash
npm install
npm run dev
```

Open the address Vite prints, or its LAN address on a phone on the same Wi-Fi. `showcase.html` is the asset gallery.

## Build

```bash
npm run build
```

Upload `dist/` to any static host. See PROJECT-NOTES.md for how everything works.
